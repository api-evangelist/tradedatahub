# TradeDataHub Public API

A marketplace API for downloadable CSV datasets of verified U.S. contractor and trade-business listings. Offers a free, unauthenticated REST discovery API under /api/v1/ (coverage, states, trades, cities, datasets, previews, pricing) plus paid dataset retrieval via x402 (testnet-only, Base Sepolia). Backed by an OpenAPI 3.1.0 contract and llms.txt/llms-full.txt agent guides.
